## Ожидаемый ответ

Команда git stash push -u сохраняет отслеживаемые изменения, включая staged и
unstaged, а также неотслеживаемые файлы. После сохранения рабочая директория
становится чистой, что позволяет создать отдельный hotfix.

Команда git stash apply --index восстанавливает изменения и пытается вернуть их
исходное распределение между индексом и рабочей директорией. При этом запись
stash не удаляется.

## Моё объяснение

Сначала я подготовил три вида изменений: staged и unstaged в progress.txt, а
также untracked-файл draft-08.txt.

Затем сохранил незавершённую работу в stash с флагом -u. После этого создал
отдельный коммит hotfix 08.

Далее восстановил изменения через git stash apply --index. Это позволило
продолжить прежнюю работу после hotfix, сохранив разделение изменений между
индексом и рабочей директорией.

В конце создал коммит a8c45ee. Команда git status --short показала, что рабочая
директория чистая.
