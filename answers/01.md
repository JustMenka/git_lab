## Ожидаемый ответ

Soft меняет только HEAD; mixed меняет HEAD и индекс; hard меняет HEAD, индекс и
рабочий файл.

## Моё объяснение

В ходе задания я проверил три режима команды git reset.

git reset --soft

После выполнения команды HEAD переместился с коммита B на A. При этом изменение
файла reset-demo.txt осталось в индексе, поэтому git diff --cached показывал
изменение A → B, а git diff был пустым.

git reset --mixed

а После сброса HEAD также переместился с B на A, однако индекс вернулся к
состоянию A. Изменение сохранилось только в рабочей директории. Поэтому git diff
--cached был пустым, а обычный git diff показывал изменение mixed-A → mixed-B.

git reset --hard

После выполнения команды HEAD, индекс и рабочая директория вернулись к состоянию
A. Файл reset-demo.txt стал содержать hard-A. Команды git status --short, git
diff и git diff --cached не показали изменений.

Вывод

Разница между тремя режимами заключается в том, какие состояния Git изменяются.
--soft перемещает только HEAD, --mixed дополнительно сбрасывает индекс, а --hard
также изменяет рабочие файлы.

### Три режима reset

| Режим | SHA A   | SHA B   | `status --short` | staged diff | unstaged diff     | файл    |
| ----- | ------- | ------- | ---------------- | ----------- | ----------------- | ------- |
| soft  | d3d98f2 | fdb5c39 | M reset-demo.txt | A → B       | Пусто             | B       |
| mixed | ec656e3 | d7b1842 | M reset-demo.txt | Пусто       | mixed-A → mixed-B | mixed-B |
| hard  | 47da160 | 7981d1e | Пусто            | Пусто       | Пусто             | hard-A  |

Ожидаемый ответ: soft меняет только HEAD; mixed меняет HEAD и индекс; hard
меняет HEAD, индекс и рабочий файл.
