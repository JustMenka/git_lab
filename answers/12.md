## Ожидаемый ответ

Файл .gitignore задаёт правила игнорирования, но не прекращает отслеживание
файлов, уже добавленных в Git. Команда git rm --cached удаляет файл из индекса,
сохраняя его на диске.

## Моё объяснение

В ходе задания я добавил правила игнорирования в .gitignore, включая правило
\*.log.

После этого проверил правило командой git check-ignore -v debug.log. Git
показал, что файл debug.log соответствует правилу \*.log, находящемуся во второй
строке .gitignore.

Поскольку debug.log ранее отслеживался Git, одного добавления правила было
недостаточно. Поэтому я выполнил git rm --cached debug.log, чтобы удалить файл
из индекса, не удаляя его из рабочего каталога.

Проверка git ls-files debug.log ничего не вывела, то есть файл больше не
отслеживается. При этом ls -l debug.log подтвердил, что файл остался на диске.

Таким образом, фактический результат соответствует ожидаемому: debug.log
перестал отслеживаться Git и теперь игнорируется согласно .gitignore.
