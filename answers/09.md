## Ожидаемый ответ

После git reset --hard указатель ветки перемещается на выбранный коммит, а
индекс и рабочая директория приводятся к его состоянию. Коммит LOST перестаёт
отображаться в обычной истории ветки, но его объект не удаляется немедленно.

С помощью git reflog можно найти прежнее положение HEAD и восстановить
потерянный коммит по SHA.

## Моё объяснение

Я создал локальный коммит LOST с SHA d6b87fe, затем выполнил git reset --hard
9f973bd.

После сброса коммит LOST исчез из вывода git log, а файл lost-09.txt
отсутствовал в рабочей директории.

Команда git reflog -8 показала запись HEAD@{1}: commit: LOST, благодаря которой
я нашёл SHA потерянного коммита.

Затем я выполнил git reset --hard d6b87fe, восстановил прежнюю историю и
опубликовал коммит на GitHub. Проверка показала, что локальная и удалённая ветки
совпадают, а рабочая директория чистая.
