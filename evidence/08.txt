=== 1. Исходное состояние ===

Команда:
git status --short

Результат:
MM progress.txt
?? draft-08.txt

Команда:
git diff --cached

Результат:
В progress.txt добавлена строка:
+Изменение staged

Команда:
git diff

Результат:
В progress.txt добавлена строка:
+Изменение unstaged

Команда:
cat draft-08.txt

Результат:
Новый файл для stash

=== 2. Сохранение изменений в stash ===

Команда:
git stash push -u -m "task 08: незавершённая работа"

Команда:
git stash list

Результат:
stash@{0}: On feature/task-08: task 08: незавершённая работа

Флаг -u позволяет включить неотслеживаемый файл draft-08.txt.

=== 3. Создание hotfix ===

Создан отдельный коммит:

a369517 hotfix 08

=== 4. Восстановление незавершённой работы ===

Команда:
git stash apply --index

Результат:
Изменения восстановлены после создания hotfix.

Проверяемое состояние:
progress.txt — staged и unstaged изменения
draft-08.txt — untracked файл

Команда apply сохраняет запись stash.
Флаг --index восстанавливает также состояние индекса.

=== 5. Итоговые коммиты ===

Команда:
git log --oneline -5

Результат:
a8c45ee stash 08
a369517 hotfix 08
85ae64f stash 08: подготовить файлы
5632641 task 08: форма и инструкция
5306119 История 12: изменение проекта

Команда:
git status --short

Результат:
(пустой вывод — рабочая директория чистая)

=== 6. Вывод ===

Успешно сохранены staged, unstaged и untracked изменения.
Создан отдельный hotfix.
Незавершённая работа восстановлена через git stash apply --index.
После сохранения восстановленных изменений в коммите рабочая директория чистая.
